# Aayush & Anjali Wedding Invitation

A romantic, mobile-friendly wedding invitation website for Aayush and Anjali's engagement and wedding celebration in Palampur, Himachal Pradesh.

## Included sections

- Hero section with countdown
- Love story timeline
- Event schedule for engagement and wedding day
- Photo gallery
- Travel guidance
- Accommodation recommendations
- RSVP form with local storage saving

## Run locally

From this project folder, start a local HTTP server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Free hosting options

This project is a static website, so it can be hosted for free on platforms like:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

## Recommended quick deploy flow

1. Push this project to a GitHub repository.
2. On GitHub, open the repository settings.
3. Enable Pages and choose the main branch root folder.
4. Your site will be published at a free GitHub Pages URL.

## Customisation

Update the names, dates, venue, travel notes, hotel suggestions, and RSVP text directly in:

- `index.html`
- `styles.css`
- `script.js`

If you want to replace the placeholder gallery images with your own family photos, replace the image URLs in `index.html` with your photo links.
